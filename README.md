# astrbot_plugin_class_notice

_✨ 上课下课提醒 · 多班级课表导入 / 查询 / 定时推送 ✨_

把课表（`.ics` / `.csv` / `.json` / 文本）导入后，机器人会在**上课前**和**下课前**按点提醒到指定的私聊或群，支持**多班级**独立管理，每天定时推送当天课程（**图片 / 文本可切换**），同时支持 `/课表` 查询当天、明天、指定日期、本周的课程。

> 所有 `/课表` 指令都是 **终结命令**：不会被送去 LLM，也不会进入聊天记忆与学习数据。

## ✨ 功能

| 功能 | 说明 |
| --- | --- |
| 🏫 多班级 | 每个班级独立课表、独立推送目标、独立提醒策略；`/课表 班级` 系列命令可在群里直接管理 |
| 📥 课表导入 | 支持 `.ics`（iCalendar）/ `.csv` / `.json` / 纯文本；自动处理 UTC 时区、`RRULE` 周重复、`EXDATE` |
| 🧹 脏数据过滤 | 自动跳过课程表 App 写进日历的「N分钟后上课/下课」提醒条目，以及零时长 / 已取消事件 |
| 🔗 连堂合并 | 同一天、同名、同地点、间隔 ≤ 20 分钟的相邻节次自动合并成一段 |
| 🔍 课表查询 | `/课表 6` 今天 / 明天 / 本周 / 任意日期；输出带「查询日期」提示，不会混淆日期 |
| ✍️ 手动录日程 | 面板逐条添加，或 `/课表 6 添加 …`；与 `.ics` 导入互不覆盖（临时加课、考试、班会） |
| 🖼️ 图片推送 | 每日推送支持 图片 / 文本 / auto（图片优先、失败自动回退文本）三种格式 |
| ⏰ 定时提醒 | 上课前 N 分钟 / 下课前 M 分钟，可分别开关 |
| 📅 每日课程推送 | 每天固定时间自动推送当天全部课程，当天无课也会提示 |
| 🚀 立即 / 测试推送 | 手动触发一次推送，结果回显当前生效的推送配置，方便验证链路 |
| 📢 多目标推送 | 一次提醒同时发到多个私聊 / 群 |
| 🛡️ 与聊天隔离 | 指令优先级 1000 + `stop_event()`，聊天类插件将完全看不到这些消息 |

**无第三方依赖**，只用标准库（`sqlite3` / `zoneinfo` / `asyncio`）。

## 📦 安装

1. 把 `astrbot_plugin_class_notice` 整个目录放进 `AstrBot/data/plugins/`
2. 面板 → 插件 → 重载（或重启 AstrBot）
3. 面板 → 插件 → 上课下课提醒 → 配置 → 填好推送目标（或直接用 `/课表 班级` 命令管理）

## ⚙️ 配置说明

### 全局配置

| 配置项 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `enabled` | bool | true | 关闭后查询仍可用，只是不再主动推送 |
| `timezone` | string | Asia/Shanghai | 时区 |
| `notify_sessions` | list | [] | 全局兜底推送目标，多班级时建议写在每个 class 里 |
| `confirm_session` | string | 空 | 测试/确认信息发到哪个会话；留空 = 回到发指令的会话 |
| `advance_minutes` | int | 20 | 上课前提前提醒分钟数 |
| `end_advance_minutes` | int | 5 | 下课前提前提醒分钟数 |
| `notify_class_start` | bool | true | 是否推送上课提醒 |
| `notify_class_end` | bool | true | 是否推送下课提醒 |
| `daily_push_enable` | bool | false | 是否启用每日课程推送（兜底默认值） |
| `daily_push_time` | string | "08:00" | 每日推送时间（兜底默认值） |
| `push_format` | string | auto | 推送格式：text / image / auto（推荐 auto） |
| `push_image_title` | string | 空 | 图片顶部标题；留空用班级名 |
| `default_class_id` | string | 空 | 不带班级参数时使用的默认班级 |
| `manual_entries` | list | [] | 手动录入的日程，逐条添加 |
| `import_path` | string | 空 | 课表文件路径；留空自动找插件数据目录下的 `timetable.`+后缀 |
| `classes` | list | [] | **多班级配置**，见下 |

### 多班级 `classes` 结构

每个班级独立配置课表、推送目标、提醒策略：

```json
"classes": [
  {
    "id": "6",
    "name": "6班",
    "notify_sessions": ["沃:GroupMessage:xxxxxxxxxxxxxxxxxxxx"],
    "confirm_session": "沃:FriendMessage:xxxxxxxxxxxxxxxxxxxx",
    "advance_minutes": 40,
    "end_advance_minutes": 5,
    "notify_class_start": true,
    "notify_class_end": true,
    "daily_push_enable": true,
    "daily_push_time": "07:30",
    "push_format": "auto",
    "push_image_title": "6班",
    "manual_entries": [
      "2026-09-16 08:00-09:40 高等数学 @教三201"
    ]
  }
]
```

- `notify_sessions` 是**列表**：想推到哪里就加一行。
- 会话格式：`platform:message_type:session_id`，如 `沃:FriendMessage:xxx`、`沃:GroupMessage:xxx`。
- `confirm_session` 决定「测试推送 / 立即推送」的结果回执发到哪，填私聊可以保证**群里只收通知、没有回执**。
- 所有配置均可通过面板修改，也可以用 `/课表 班级` 命令直接改（命令修改会自动保存到配置文件）。

### 手动录入日程格式

```
2026-09-16 08:00-09:40 高等数学 @教三201
2026-10-01 19:00-20:30 班会 @主楼-100
9/20 14:00-15:40 补课 @教1-214
```

- 日期：`2026-09-16` / `2026/9/16` / `2026年9月16日` / `9/16` / `9-16` / `9月16日` / `0916`（只写月日自动补年份）
- 时间分隔：`-` / `~` / `至`；`@地点` 可省略
- `#` 开头的行会被忽略；解析失败的行不会报错，会在日志和 `/课表 状态` 里提示

## 📄 课表文件格式

### 1. `.ics`（推荐）

任何日历导出的 iCalendar 文件均可，例如：超级课程表 / 极简课程表 → 同步到手机日历 → 网页导出 `.ics`

自动处理：

- `DTSTART` 为 UTC（结尾带 `Z`）→ 按 `timezone` 换算
- `FREQ=WEEKLY` 的 `RRULE`（含 `INTERVAL` / `COUNT` / `UNTIL`）
- `EXDATE` 排除日、`STATUS:CANCELLED` 取消事件
- 全天事件（`VALUE=DATE`）会被跳过
- 标题形如「10分钟后上课:xxx」的 App 提醒条目会被跳过

### 2. `.csv` / `.tsv`

表头支持中英文（日期 / date、开始时间 / start、结束时间 / end、课程 / name、地点 / location、老师 / teacher）：

```
日期,开始时间,结束时间,课程,地点,老师
2026-09-07,08:00,09:25,高等数学,教三201,王老师
```

模板见 `examples/timetable.example.csv`。

### 3. `.json`

```json
[
  {"day": "2026-09-07", "start": "08:00", "end": "09:25", "name": "高等数学", "location": "教三201"}
]
```

### 4. 纯文本

每行一条：`2026-09-07 08:00-09:25 高等数学 @教三201`

## 🔔 推送机制

### 上下课提醒

```
上课前 advance_minutes 分钟   →   ⏰ 20 分钟后上课 · 09:45-11:55
                                  嵌入式系统及应用  @教1-214

下课前 end_advance_minutes 分钟 →   🔔 5 分钟后下课 · 11:55
                                  嵌入式系统及应用  @教1-214
```

### 每日课程推送

```
每天 daily_push_time 整点   →   📅 10月14日 周二  共 4 节
1. 08:20-09:55  计算机网络  @K2-502
2. 13:30-15:05  Python程序设计  @A110（公共机房11）
3. 15:25-17:00  Web企业级开发  @A313（达内共建实训基地）
```

- 当天无课时推送：`📅 10月10日 周六\n没有课，好好休息～`
- 每个自然日每个班级只推送一次，重启后当天已推送不会重发
- 推送时间与上下课提醒共用同一套 `notify_sessions`
- 调度器每 **20 秒**检查一次当天课表
- 提醒点前后 **5 分钟内**触发有效（重启后能补发一次；超过 5 分钟不补发）
- 同一条提醒不会重复发
- 推送走 `Context.send_message()` 旁路发送，**不经过聊天管道**，不会触发其他插件的回复

## 🛡️ 与聊天隔离

| 消息 | 行为 |
| --- | --- |
| `/课表 …` 指令 | 处理完立刻 `stop_event()`，聊天类插件完全看不到 |
| 推送出去的通知 | 旁路发送，不进入对话历史，不触发 `after_message_sent` 钩子 |

实现要点：

- `@filter.command("课表", alias={"课程表"}, priority=1000)` —— 优先级高于聊天类插件（0），但**低于 wakepro 的 99999**
- 命令参数使用 `GreedyStr` 贪婪接收，`/课表 6 明天` 的完整参数不会被 AstrBot 截断
- **先 `yield` 结果再 `stop_event()`** —— 顺序反了会导致指令回复发不出去
